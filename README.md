Step

A simple web project built with HTML, CSS, JavaScript, and PHP.

How to Run Locally

1. **Download the project**
   Click the green **Code** button on GitHub and select **Download ZIP**, then extract it.

2. **Move to XAMPP**
   Place the extracted project folder into your XAMPP directory:
   `C:\xampp\htdocs\`

3. **Start XAMPP**
   Open **XAMPP Control Panel** and click **Start** next to **Apache** (and **MySQL** if your project uses a database).

4. **Open in Browser**
   Go to `http://localhost/Project/` in your browser.
